# Delivery verification evidence

These files document software tests, data preparation and deliberately small real molecular pilots. They are **not** the formal 960-cell research matrix and must not be copied into manuscript performance tables. Full-report contract tests use artificial data and are labelled accordingly. Raw datasets, molecular prediction rows and trained model weights are not committed here.

The final source hashes and completion limits are recorded in `../DELIVERY_VERIFICATION.json`. Full experimental outputs will be generated by the operator command and reviewed by the authors.
