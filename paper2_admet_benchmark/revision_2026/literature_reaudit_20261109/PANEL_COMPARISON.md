# 多终点面板与实验预算方向：逐项重审

日期：2026-11-09。结论：**撤销“QComp已经做过，因此整个面板预算方向不值得研究”的排除。** QComp是直接相邻方法和应当比较的强对照，但已核验内容并未与“有限批次、面板联合测量、逐终点双类错误、净免测成本”的完整问题重合。这只是恢复候选资格，尚未证明新颖性或有效性。

## 核验到的版本

- QComp正式身份为 *QComp: A QSAR-Based Imputation Framework for Drug Discovery*, JCIM 65(15), 7862–7873，2025-07-28上线，DOI [10.1021/acs.jcim.5c00059](https://doi.org/10.1021/acs.jcim.5c00059)。**正式全文403，未读到accepted manuscript。**
- 完整读取的论文是作者[arXiv:2405.11703v1](https://arxiv.org/html/2405.11703v1)，2024-05-20；arXiv版本历史只有v1。其题名为 *QComp: A QSAR-Based Data Completion Framework for Drug Discovery*，作者名单与正式版也有变化，不能标成2025正式全文。
- 已读取正式论文链接的[官方仓库](https://github.com/MSDLLCpapers/QComp) README、递归文件树及model.py。没有找到accepted manuscript。v1方法中B、b可训练；当前官方model.py却将其固定为单位矩阵和零偏置，关闭这一校准。这说明具体实现确有版本差异。
- 以下QComp算法与局限比较明确对应2024v1；当前代码只核验了共享协方差及条件高斯插补核心。正式版是否改变实验选择细节仍未确认。

## 必须纠正的排除规则

1. “多任务/补全/主动学习已有”只能否定把这些宽泛组件本身当新贡献，不能否定一个具体的新决策问题。
2. “QComp已选择下一测定”要求我们比较它的GOC策略；不等于它已经优化有限库双类风险下的净免测成本。
3. “加成本”也不自动创新：ALCATRAs已经明确把任务成本放进策略。真正需要比较的是买到何种信息、信息在何处使用、约束什么风险、为何最优动作会改变。
4. “一项实验给多个读出”也不自动创新：QComp已经讨论共同测量产生的共缺结构。研究贡献必须来自利用该结构的统计/决策机制。
5. “多风险保证已有”不意味着任何新实验协议都免费获得保证；i.i.d.总体风险与固定总体无放回抽样的实际类别分母不同。也不能仅把已知工具拼接后就称新定理。

## 恢复一个可论证的候选，不立即铺实验

**面板联合观测驱动的有限库多终点放行。** 令一次动作a揭示同一分子的预先定义终点集合S_a，成本c_a；决策目标是减少整库剩余真实测定成本，同时约束每个目标终点的FNR/FPR。这里的差异应落在联合标签模式约束如何改变风险可行域和测定动作，而不是模型名字。

先分析可分解情形：若逐终点风险只依赖自身状态，联合不确定集在各终点的投影不变，行动与成本也可分，则仅改变相关性不会改变最优成本。面板共享成本和相关信息的价值还需分开识别。随后用公式或小型构造完成以下比较：

- 明确哪个真实机制打破可分解性，例如不可拆分的面板动作、观测后其他终点信息更新或跨终点效用。再构造条件匹配的有限库，检验联合机制与“独立终点证书＋同一成本表”的动作是否有实质差异；不默认相关性必然有收益。
- 说明QComp的方差降低、ALCATRAs的预测改进/成本与本项目的剩余测定成本为何可能给出不同最优动作；随后用公式、构造或轻量原型解释差异条件。若所有差异仅来自人为设置成本，贡献仍不足。

这是需要继续查邻近文献和推导的机制候选，不是已经成立的新方法。没有依据把旧四步lookahead的阴性结果外推为面板方向不可能；同样不能因为未找到完全同名论文就宣布创新成立。

## 本次访问边界

原文读取与证据定位只支持上表具体陈述。QComp最终版全文未获得，保留为需补齐的一项，而不是用2024预印本代替2025发表版。IBC的关键方法/实验经OUP原文与PMC索引正文核验；ALCATRAs相关正文由arXiv PDF读取；Nguyen等由arXiv全文读取。三者都是应比较的邻居，均不是目前整方向排除的充分依据。
