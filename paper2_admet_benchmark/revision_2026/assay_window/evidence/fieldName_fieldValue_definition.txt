REPRODUCIBILITY		Missing value for REPRODUCIBILITY indicates that the assay was not run using replicates, and so the reproducibility could not be assessed.
REPRODUCIBILITY	active_match	A value assigned per sample/protocol/SAMPLE_DATA_TYPE indicating consistency in the curve fitting of the replicates, and a minimum of curves being classified as 'inactive'.  See chapter12.pdf for details.
REPRODUCIBILITY	inactive_match	A value assigned per sample/protocol/SAMPLE_DATA_TYPE indicating consistency in the curve fitting of the replicates, but includes more than 50% of curves being classified as 'inactive'.  See chapter12.pdf for details.
REPRODUCIBILITY	mismatch	A values assigned per sample/protocol/SAMPLE_DATA indicating inconsistency in the curve fitting of the replicates.  See chapter12.pdf for details.
REPRODUCIBILITY	possible_mismatch	A values assigned per sample/protocol/SAMPLE_DATA indicating inconsistency in the curve fitting of the replicates.  A value of possible_mismatch is the same as that of a mismatch, except with a threshold of average score > 2, rather than 2.5.  See chapter12.pdf describing 'mismatch' for details.
REPRODUCIBILITY	inconclusive	A value assigned per sample/protocol/SAMPLE_DATA_TYPE. All other cases that don't fall into one of the above reproducibility categories.
CURVE_RANK	numerical	Numerical value representing the curve.  The sign of the number represents the nature of the curve with agonist being a positive value and antagonist being negative. The numerical value represents the quality of the response curve, with higher values indicating a higher quality of curve.
AC50		A missing value indicates there is no significant concentration response and no curve fit.
