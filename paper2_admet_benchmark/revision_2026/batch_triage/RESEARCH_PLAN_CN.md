# 固定分子批次中的双类错误控制与实验分配

更新：2026-11-08。本方案研究固定分子批次中，如何同时认证两类错误并减少测定数量。实现、理论说明和运行入口均在本目录。

## 要解决的具体问题

给定已经排好的一批待测分子和冻结模型分数，我们可以付出一次真实终点测定的成本，查看其中一个分子的标签。最终每个分子必须落入三种状态之一：自动判为 0、自动判为 1、完成测定。目标是在**整个批次的真实阳性中，自动判阴的比例不超过 10%；整个批次的真实阴性中，自动判阳的比例也不超过 10%**，并以至少 95% 的审核随机化置信度认证这两个条件，同时尽量减少最终需要测定的分子数。

这里“自动判为 0/1”只是该数据集终点的标签，不统一称为“安全/有毒”或“放行/淘汰”。AMES 阳性指细菌致突变试验阳性；hERG 指其数据集定义的通道抑制标签；DILI 是药物性肝损伤关联标签；CYP2D6_Veith 是该酶筛选实验的阳性标签。模型分数用于组织测定和决策，不能把临床意义不同的标签混成一个毒性终点。

和旧稿的关系很直接：旧实验显示，扩张预测集合本身就可能提高覆盖率，却没有显示 TAME 优于同预算简单概率排序。新研究直接计量**为了获得可认证的最终决策，到底花了多少次测定**。它付费获得目标批次标签，因此不能与零目标标签的方法按“相同自动决策数”简单比较后宣称优越。

## 本次要检验的三个增量

1. **保留两个未知类别分母的耦合。** 未测分子既可能贡献错误，也可能改变全批次阳性或阴性总数。利用同一组阳性计数置信区间，精确求出两类错误的最坏情形，避免把错误数上界和类别总数下界拆开后产生额外保守性。
2. **审核后联合选择 0、1 或测定。** 动作作用于预先冻结的“分数 × 化学支持度”分层；通过整数优化选择整个剩余层的动作。它允许不同化学支持层采用不同决策，不被限制为一条分数轴上的两个阈值。
3. **按预计能减少的最终测定需求取标签。** 查询策略模拟下一小块标签对证书和最优决策的影响，再决定测哪个层。实际层内仍均匀无放回抽样。模型对模拟结果的预测可能错误；这影响效率，不进入有效性证书。

上述增量需要分别通过实验支持。计算上使用冻结分层的粗粒度动作，因此所谓最优只是该动作空间和当前证书内的最优，不是任意逐分子决策或整个未来实验路径的全局最优。计数置信序列、随机审核、主动标签、审核后调整阈值、单候选区的分母耦合以及 MILP 都有已有研究。详细最近邻和推导见 [THEORY_AND_POSITIONING.md](THEORY_AND_POSITIONING.md)。

## 成本和错误怎样算

设整个可审核批次有 `N` 个分子；当前已经测定 `q` 个，未测分子中自动判为 0、自动判为 1、仍需测定的数量分别为 `A0`、`A1`、`D`。

- 最终总测定数：`C = q + D`。
- 真正节省的测定数：`S = A0 + A1 = N - C`。
- 节省比例：`S / N`。
- 假阴性暴露：`自动判为0且真实为1的数量 / 全批次真实为1的数量`。
- 假阳性暴露：`自动判为1且真实为0的数量 / 全批次真实为0的数量`。

已查询的分子必须计入测定成本，不能再算自动决策；未被自动处理的分子最终都要测定。两类错误的分母包含已经测定、最终测定和自动处理的全部批次成员；不是自动决策集合内的错误比例，也不是 false discovery/omission rate。

模拟把公开数据中的既有终点标签当作查询返回值。测定后按该标签处理，因而不再发生相对于这个标签的模型判别错误。这没有证明真实实验不存在测量噪声、重复测定差异或生物学不确定性。

若真实某类不存在，计算上将该类错误率记为 0，但必须显示真实类别数与 `class_absence_possible` 标志；空类不能被表述为该类控制得到实证验证。

## 冻结的首轮实验

| 项目 | 默认安排 |
|---|---|
| 分子任务 | AMES、hERG、DILI、CYP2D6_Veith，各自固定 random/scaffold 划分，共 8 个批次 |
| 目标规模 | 原划分约为 AMES 1,451、hERG 122、DILI 95、CYP2D6 2,617；本次以清洗、可预测且有真实标签的 manifest 计数为准 |
| 模型 | 原共享 stack，fit seed 311；审核过程中不更新模型 |
| 主风险约束 | `eps_fn=0.10`、`eps_fp=0.10`、`delta=0.05` |
| 分层 | 全池分数排名分成4层，源端最大Tanimoto相似度排名分成2层，取交叉层；同值按sample ID固定排序，去除空层后记实际层数 `H` |
| 置信度分配 | 每个非空层 `delta_h=delta/H`；同一计数事件同时用于两类约束 |
| 主计数置信序列 | 查询前固定 `edge_mixture` 先验：0与全阳性各0.4，Beta-Binomial(0.5,0.5)成分0.2；不根据审核结果挑选先验 |
| 查询块 | 最多 4 个；每个真实标签都依次更新置信序列；到达记录点或层耗尽时截短 |
| 审核轨迹 | `q/N = 0, .05, .10, .20, .40`，整数化后的实际 `q` 另列 |
| 最终总成本容量 | 另报告 `C/N <= .20, .40, .60, .80` 是否可由当前证书达到；这与审核比例不是同一预算 |
| screen | AMES、CYP2D6 的两种划分，stack，审核 seeds 81001–81003，8 个方法：共 96 次策略运行 |
| formal | 全部 8 个批次，stack，审核 seeds 81001–81020，8 个方法：共 1,280 次策略运行 |
| 可选敏感性 | `--sensitivity` 单独启用3种共享 predictor × 3组错误容忍度，共11,520次策略运行；单独输出，不与主结果重复合并 |

hERG 和 DILI 的小批次仍保留。新证书不继承旧运输门控的 `n>=100` 条件；它们可能因为计数区间宽而很难节省实验。它们用于检验有限批次方法的小样本边界。四个任务的真实标签语义和两种划分始终分别呈现；五个/多个拟合种子不是新增生物样本，本轮主实验只冻结一个拟合种子。

本路线在旧 formal v3 结果审阅后提出。目标批次及其结果此前已被团队查看，本轮属于回顾性模拟审核；目标标签在策略运行期间由 oracle 隔离。

## 八个方法各自回答什么

| 方法 ID | 查询方法 | 证书及动作集合 | 隔离的问题 |
|---|---|---|---|
| `joint_lookahead` | 根据下一查询块的预测结果，比较更新后的最大未测自动决策数 | 精确耦合双类约束，分数 × 支持度层联合 0/1/测定 | 完整候选方法 |
| `joint_uniform` | 按各层剩余人数比例选择下一查询层 | 与完整方法相同的联合 MILP | 是否优于普通随机获取标签 |
| `joint_entropy` | 按剩余人数 × 平滑阳性率熵加权选层 | 相同联合 MILP | 是否只是优先查看高不确定分子 |
| `joint_neyman` | 选择相对 `N_h sqrt(p_h(1-p_h))` 目标分配缺口最大的层 | 相同联合 MILP | 是否优于经典分层分配思路 |
| `threshold_lookahead` | 同类预测查询规则 | 同一计数证书，按各非空层平均分数排序，动作限制为前缀判0、后缀判1的双阈值 | 非单链动作优化是否有价值 |
| `loose_lookahead` | 同类预测查询规则 | 将错误分子数与真实类别分母分开取界的保守证书 | 精确分母耦合是否减少保守性 |
| `score_only_lookahead` | 同类预测查询规则 | 8 个纯分数层，联合 MILP | 比较纯分数与化学支持分层，另报告实际层数差异 |
| `uniform_cs_lookahead` | 同类预测查询规则 | 保留联合 MILP，但计数证书使用查询前固定的均匀总数先验 | 边界混合先验是否提高证书效率 |

交叉分层最多有8个非空层，score-only 在本轮批次中有8个层，二者实际 `H` 不一定相同。每次运行记录 `H`、各层大小和 `delta/H`；该对照比较两种分层方案，层数及置信度分配的差异也需纳入解释。

所有方法都支付查询成本并使用相同风险目标。固定层内必须均匀无放回抽样；entropy/Neyman 只影响下一次选哪个层。输出保留层选择规则、层成员和查询流水。

`threshold_lookahead` 是共享计数证书的类条件阈值对照，用于隔离动作空间的作用。它借鉴最近邻的阈值策略并适配本研究的双类风险目标，并非 PAC Labels 原算法复现。

## 查询策略的精确含义

令 `L(state)` 是当前证书下可自动处理的未测分子数的最大值。候选层下一块大小为 `b<=4`；查询策略用平滑阳性率

`p_h = (s_h + 2 * prior_probability_h) / (n_h + 2)`

以及 Binomial 预测权重，评价该块可能出现 `0,...,b` 个阳性后的 `L`。假想状态只把当前置信区间与块末计数区间求交，不臆测未知的块内标签顺序；真实查询则逐个标签保留每一前缀。假想区间为空时，该分支的自动节省记为0。这是便于计算的模型导向预测，不是假定真实无放回标签服从独立 Binomial，也不是全局最优审核策略。实际置信推断仍使用无放回超几何计数。

评分必须计入被查询的 `b` 个分子已经失去“免测自动处理”的资格。`E[L_after]-L_now` 对应预计总测定数下降，不能另把查询标签免费算入节省，也不重复扣除同一次查询。单块预测可能低估更长程的收益；没有正预测收益时选择剩余阳性计数区间最宽的层，以固定随机种子打破并列，不在完整目标标签上调参。

每个轨迹点表示“如果此刻停止审核，再完成剩余必要测定”的决策。不能先审核到 40%，事后选 5% 时的最高节省却只支付 5% 的审核费。尚未最终提交的候选自动动作可以随审核更新；若未来真实部署已经执行了某个动作，不能在之后撤销它并把历史成本抹掉。本轮不宣称解决不可逆连续发布问题。

## 二作如何运行

从仓库根目录运行；依赖安装、缓存路径和 CLI 的实际选项以同目录执行入口与 `--help` 为准。先完成 pilot，再做小规模 screen：

```bash
python -m paper2_admet_benchmark.revision_2026.batch_triage.execute --mode pilot --cache .local/batch_triage_cache --output .local/batch_triage_pilot
python -m paper2_admet_benchmark.revision_2026.batch_triage.execute --mode screen --cache .local/batch_triage_cache --output .local/batch_triage_screen
```

中断后用相同命令加 `--resume`；不要换 seeds、分层、阈值或源代码后接着复用旧结果。先返回 screen 的完整 review ZIP 与失败记录，由我们检查可认证节省、失败情况和运行开销，再决定是否启动已经定义好的 formal：

```bash
python -m paper2_admet_benchmark.revision_2026.batch_triage.execute --mode formal --cache .local/batch_triage_cache --output .local/batch_triage_formal
```

无需重训 CoDrug/KMM 的图神经网络。数据准备优先复用有来源校验的逐分子 score manifest；旧 review ZIP 只有汇总文件，不能从 coverage/metrics 倒推出逐分子分数。没有合格缓存时，准备程序会为每个任务/划分/fit seed 生成一次冻结共享模型分数并缓存；不会为每个审核 seed 或预算重新拟合。目标真实标签由独立 oracle 保存，策略只通过记录在案的 `query` 调用获得已付费标签。

操作者按冻结配置运行并返回整个输出目录及失败日志；结果分析和论文修改由我们完成。

## 输出必须能回答的问题

每个任务、划分、方法、审核 seed 和轨迹点至少报告：

- 批次与各层大小、累计审核阳性/阴性数、计数区间、两类证书上界、类别可能为空的标志。
- 自动判 0、自动判 1、最终仍测定的数量，已查询数，**总测定数与净节省**。
- 隐藏真值仅由评估器计算的实际 FNR/FPR，以及是否任一超过目标；不能传回查询策略。
- 与同 seed 对照的配对节省差、计算时间、优化失败/置信集合为空/无可行节省的原因。
- 最终总测定容量的可满足性；若最低已认证需求高于容量，应显示不能在该容量内完成。

主图画审核比例对净节省，并同时展示最终总成本；主表分列两个风险及其证书上界。小样本/全测定/零节省的任务同样保留。先验混合会影响计数证书的保守程度：均匀总数先验在稀有错误下可能逼近全查，主实现因此预先采用边界混合。边界混合也不保证高效，必须报告先验选择及其效率敏感性，不能看到当前审核结果后换一个更好看的证书。

20 个审核 seeds 是固定批次上的随机化重复，衡量查询路径对成本的影响；它们不是20个新分子库。单任务策略差采用配对的 seed 分布和区间，主要逐任务呈现，不把所有分子/轨迹点当独立样本做显著性检验。20次中没有风险违反也不能经验性证明失败概率小于5%；理论保证来自证书，重复试验用于发现实现错误与展示保守性。跨任务汇总须保留端点语义和批次差异。

## 怎样决定继续、缩小主张或停止

screen 检查可认证节省和运行成本。计数证书、精确约束、oracle 隔离和成本账本先通过测试；证书违规或漏记查询成本需先修复再解释结果。

实证贡献必须能分解：完整方法相对 uniform/entropy/Neyman 是否稳定降低总测定数；相对 threshold 是否显示非嵌套决策的价值；相对 loose 是否显示分母耦合的价值；相对 score-only 是否显示化学支持信息的价值；相对 uniform-CS 是否显示先验选择的效率影响。部件的作用由对应对照的成本差解释，并同时报告计算代价。

如果大多数任务仍需近乎全测，或完整方法与简单对照没有有意义的成本差，结论应聚焦有限批次认证的效率限制。有跨任务一致的节省时，再完成 formal，并据实际结果组织论文。
