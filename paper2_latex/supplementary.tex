\section{Scope and frozen evidence boundary}

This Supporting Information accompanies the confirmatory ADMET reliability benchmark reported in the main manuscript. The evidence boundary is identical to that of the main analysis. Development splits and seed~99 were excluded from scientific conclusions. Random and scaffold analyses used confirmatory seeds 101--110, and similarity-cluster analyses used seeds 101--105. Model families were not treated as independent inferential replicates. Method contrasts were paired within the same endpoint, split, seed, model, and classification imbalance regime.

The tables below are generated directly from the versioned, integrity-checked manuscript result package. The generation step performs no model fitting, split construction, conformal threshold estimation, method selection, or additional hypothesis testing. Descriptive cross-model averages are used for compact endpoint- and split-level reporting. Where inferential stability is discussed, paired-effect tables report the number of frozen model-specific cross-seed 95\% confidence intervals that lie entirely above or below zero in the stated direction.

\section{Reproducibility and machine-readable files}

From the repository root, the Supporting Information tables and PDF are generated with:

\begin{verbatim}
conda activate aidd_paper
python paper2_admet_benchmark/scripts/35_build_supporting_information.py
cd paper2_latex
latexmk -C supplementary.tex
latexmk -pdf -interaction=nonstopmode -file-line-error -halt-on-error supplementary.tex
\end{verbatim}

The builder reads only the frozen CSV files under \path{paper2_admet_benchmark/results/manuscript_assets/}. It does not require local row-level prediction files, trained model binaries, or intermediate aggregation tables. The machine-readable CSVs remain the authoritative source for full decimal precision and secondary metrics. High-domain ClinTox subgroup results under scaffold and similarity-cluster splitting should be treated as descriptive because positive-class support can be sparse. No sparse or adverse result was removed after inspection.
