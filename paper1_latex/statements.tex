\section*{Data and Code Availability}

All datasets used in this study are public molecular-property datasets. The authoritative submission-version workflow, frozen protocols, preprocessing and split-generation scripts, partition manifests, model-running and audit scripts, result tables, figure-generation code, LaTeX source, and Supporting Information are maintained in the public \href{https://github.com/DCarchimonde/aidd-paper-factory/tree/paper1-rebuild-v3}{aidd-paper-factory repository (branch \texttt{paper1-rebuild-v3})}. A dedicated reproducibility mirror is maintained in the \href{https://github.com/DCarchimonde/split-diagnostic-molecular-benchmark}{split-diagnostic-molecular-benchmark repository}. The exact validated submission state is identified by the Git commit recorded in the machine-readable \texttt{BUILD\_MANIFEST.json} distributed with the submission bundle; machine-readable hashes in the Supporting Information identify the frozen molecular and partition artifacts used for the reported analyses.
