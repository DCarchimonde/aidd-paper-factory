\section{Model and Computational Completeness}
\label{sec:si-completeness}

The frozen production suite contained 1,338 expected model jobs across the main classification analysis, main regression analysis, and acyclic singleton sensitivity. The completeness gate reported 1,338/1,338 current jobs, with no missing, stale, or invalid job. The dominant-fragment sensitivity added 360/360 completed jobs. Across both stages, 1,698 pre-specified model fits entered the audit outputs. Model seeds were separated from partition seeds; LR/ridge were deterministic under the fixed implementation, while production RF/XGB fits used model seed 17.

\section{Reproducibility and Artifact Map}
\label{sec:si-reproducibility}

The Paper 1 v3 workflow is organized as an auditable sequence rather than a set of result-specific scripts. Key components are:
\begin{itemize}
\item \path{shared_utils/cleaning_policy_v2.py}: canonical molecular cleaning, duplicate decisions, and lineage;
\item \path{shared_utils/scaffold_identity.py}: canonical scaffold identities, acyclic sentinel policy, split assertions, and partition hashing;
\item \path{shared_utils/split_candidate_pool_v3.py}: fixed-budget target-blind candidate generation and exact-size paired selection;
\item \path{paper1_leakage_benchmark/scripts/05_audit_candidate_pool_splits_v3.py}: split construction and candidate-pool diagnostics;
\item \path{paper1_leakage_benchmark/scripts/06_audit_candidate_budget_v3.py}: candidate-budget audit;
\item \path{paper1_leakage_benchmark/scripts/07_freeze_manifests_v3.py}: production-manifest and artifact freezing;
\item \path{paper1_leakage_benchmark/scripts/09_run_models_v3.py}: manifest-driven predictive fitting;
\item \path{paper1_leakage_benchmark/scripts/11_audit_model_completeness_v3.py}: production completeness gate;
\item \path{paper1_leakage_benchmark/scripts/12_analyze_partition_effects_v3.py}: partition-level primary and acyclic-sensitivity inference;
\item \path{paper1_leakage_benchmark/scripts/13_audit_rdkit_hydrogen_warnings_v3.py}: isolated-hydrogen audit;
\item \path{paper1_leakage_benchmark/scripts/14_audit_multifragment_standardization_v3.py}: multi-component structural audit;
\item \path{paper1_leakage_benchmark/scripts/15_run_parent_fragment_sensitivity_v3.py}: frozen dominant-fragment classification sensitivity pipeline;
\item \path{paper1_leakage_benchmark/scripts/16_build_manuscript_assets_v3.py}: figures generated directly from authoritative v3 result tables.
\end{itemize}

The authoritative experimental protocols are recorded in \path{paper1_leakage_benchmark/REBUILD_PROTOCOL_V3.md}, \path{paper1_leakage_benchmark/MODEL_PROTOCOL_V3.md}, and the frozen dominant-fragment sensitivity protocol. Machine-readable manifests, registries, summary tables, and job metadata preserve the mapping from molecular records to every reported partition and fitted result.
