\section{Reproducibility and Artifact Map}
\label{sec:si-repro}

The authoritative workflow is organized as a pre-outcome audit sequence. Core components include \texttt{shared\_utils/cleaning\_policy\_v2.py} for molecular identity and lineage; \texttt{shared\_utils/scaffold\_identity.py} for scaffold semantics and partition hashing; \texttt{shared\_utils/split\_candidate\_pool\_v3.py} for target-blind candidate generation and exact-size pairing; scripts 05--12 for split auditing, freezing, model readiness, fitting, completeness, and partition-level inference; scripts 13--15 for disconnected-component sensitivity; script 20 for the Q1 scientific controls; and script 21 for publication-size figures. The frozen protocols are recorded in \texttt{REBUILD\_PROTOCOL\_V3.md}, \texttt{MODEL\_PROTOCOL\_V3.md}, and \texttt{PARENT\_FRAGMENT\_SENSITIVITY\_PROTOCOL\_V3.md}.
