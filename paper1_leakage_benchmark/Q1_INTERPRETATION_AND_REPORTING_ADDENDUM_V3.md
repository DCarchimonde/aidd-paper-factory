# Paper 1 v3 — Q1 interpretation and reporting addendum

## Purpose

This addendum records manuscript-level scientific controls and reporting clarifications added after the frozen v3 partition and model protocols were established. It does **not** modify the frozen molecular cleaning policy, partition candidate pools, selected primary partitions, model hyperparameters, primary metrics, 18-cell primary multiplicity family, or the previously frozen acyclic and dominant-fragment sensitivity protocols.

## Clarified estimand

The paired v3 intervention is reported as **target-mean-aware partition selection**, not as causal isolation of the complete target distribution. The size-matched and target-mean-balanced partitions share:

- dataset;
- partition seed;
- scaffold identity convention;
- target-blind candidate pool and search budget; and
- exact test-set cardinality.

They need not contain the same molecules or the same scaffold composition. Changes in structural composition are therefore measured as collateral consequences of the selection rule rather than described as controlled covariates.

## Mean-only regression control

A response-only mechanistic control is calculated from the already frozen regression partition manifests. Every test observation receives the training-set target mean. No model fitting, molecular features, new split search, or outcome-dependent selection is introduced.

For each partition,

`MSE_mean_only = Var(y_test) + (mean(y_test) - mean(y_train))^2`.

The identity is checked numerically. Paired RMSE effects and paired-bootstrap intervals are reported descriptively to quantify how much benchmark difficulty can change mechanically when the split-selection objective directly reduces the train–test target-mean gap. This control is not added to the 18-cell primary multiplicity family.

## Collateral partition diagnostics

The final report explicitly compares size-matched and target-mean-balanced partitions on diagnostics that were already part of the audited partition data model, including target-shape and scaffold-composition summaries. These diagnostics are descriptive consequences of the frozen selection rule; they do not redefine the selection objective or create additional inferential families.

## Supporting metrics

Supporting classification metrics (average precision, F1, accuracy, balanced accuracy, and Brier score) and regression metrics (MAE and R-squared) were already predeclared in `MODEL_PROTOCOL_V3.md` and generated by the production analysis. The final Supporting Information surfaces these outputs for completeness without promoting them to new primary hypotheses.

## Stochastic-model seed sensitivity

`MODEL_PROTOCOL_V3.md` predeclared RF/XGB sensitivity fits on partition seeds `42, 123, 2024, 2026, 3407`, using model seeds `29` and `43` in addition to production seed `17`. The final Q1 build completes and reports these runs. Repeated model seeds remain robustness checks and never increase the partition-level inferential sample size.

## Reporting language

The final manuscript uses language such as "no corrected evidence of a target-balanced advantage" for inconclusive classification cells. It does not treat failure to meet the corrected decision rule as proof of equivalence. Likewise, regression improvements are interpreted jointly with the mean-only control and scaffold-semantics sensitivity rather than as a universal law that target balancing improves molecular regression.

## Reproducibility

The final one-command build records the Git commit, software environment, key result tables, publication-size figures, manuscript PDF, Supporting Information PDF, and a build manifest. A final immutable release/tag should be created only after the compiled PDFs have passed visual and consistency audit.
